# Changelog

All notable changes to the installers are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/).

The setup has its own version, separate from the command line it contains. Each release lists the version inside it.
