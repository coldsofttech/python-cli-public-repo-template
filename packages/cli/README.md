# example-cli

Command line for the example project, built on [Typer](https://typer.tiangolo.com/) and [Rich](https://rich.readthedocs.io/). It only parses input and shows output; the logic is in `example-package`.

```sh
uvx --from example-cli example-cli --help
```

Rename it to your CLI's name. See the [CLI reference](../../docs/cli.md).
